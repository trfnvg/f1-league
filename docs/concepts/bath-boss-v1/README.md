Создано встроенной генерацией GPT. Это визуальные материалы для следующего этапа разработки; бой ещё не подключён к игре.

План фаз: 8–6 жизней — обучение пузырям и одиночному БАН; 5–3 — последовательные удары и скользкая пена; 2–1 — раскачивание, волна пены и последнее крепление. Один удар по медали снимает одну жизнь. Предупреждения и достижимый безопасный путь обязательны.

При интеграции: нарезать и изолировать кадры, выровнять ванну по общей опоре, отделить функциональную медаль/эффекты от рисунка, проверить прозрачные края и масштаб на телефоне. Нарисованная арена — ориентир композиции, а не готовая статичная сцена с вшитым HUD.
