# Страницы ошибок

При `DEBUG=False` обработчики из `league.error_views` показывают страницы
403, 404 и 500 в стиле Fastlap. Ошибка CSRF использует отдельный обработчик
`CSRF_FAILURE_VIEW`, в том числе при включённом DEBUG.

Шаблон автономный: без базы данных, контекстных процессоров, CDN, JavaScript
и поиска файлов через static manifest. HTTP-код сохраняется, кэширование
запрещено. Технические сообщения исключений и причина отклонения CSRF
пользователю не раскрываются.

Кнопка повторного открытия выполняет только GET по безопасному локальному
пути без query string. Отклонённый POST не повторяется автоматически.
Страница 500 после POST предлагает только переход на главную.
Защита CSRF, настройки cookies и проверка Origin/Referer не ослабляются.

Эти страницы относятся к ошибкам, обработанным Django. Ошибки прокси или
недоступность самого процесса приложения настраиваются отдельно у хостинга.

На странице приглашения активный участник выбранного сезона видит
«Открыть лигу». Для нового участника или участника без записи в этом сезоне
сохраняется обычное подтверждение вступления через POST.
