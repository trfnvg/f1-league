# Участники и роли

Список находится в управлении лигой, раздел «Участники». Владелец видит всех
активных участников лиги: имя, уникальный @логин (если задан), аватар и роль.
Поиск по имени/логину и фильтр по роли работают локально, без запросов при
каждом вводе. Они не меняют состав лиги и скрыты без JavaScript; сам список
и формы работают без JavaScript.

Роли может менять только текущий владелец с активным членством.
Модератор может судить этапы и управлять приглашениями, но не менять
настройки лиги, назначать роли или удалять лигу.
Роль владельца не редактируется; передача владения не реализована.
Неактивным участникам нельзя менять роль.

При включённом JavaScript кнопка сохранения активна только после изменения
и требует подтверждения. Сервер повторно проверяет права внутри транзакции,
блокирует лигу и перечитывает участника после получения блокировки.
POST защищён CSRF. После изменения пользователь возвращается к списку
в выбранном сезоне. Повторное сохранение той же роли не создаёт запись.

Успешные изменения сохраняются в `LeagueActivity`, действие `role_changed`:
инициатор, участник, прежняя и новая роли. История не удаляется.

Миграция 0055 удаляет роль `manager`: владельцы с этой ролью получают
`player` (владение определяется отдельно через `League.owner`), остальные
управляющие — `moderator`. Неактивное членство остаётся неактивным.
Ограничение БД и серверная валидация запрещают повторное назначение manager.
Владельцы, членство, зачётные границы, приглашения и история не удаляются.
Обратная миграция не восстанавливает прежние назначения manager автоматически.

Настройки, участники и судейство открываются отдельными GET-разделами,
с сохранением выбранного сезона. Навигация работает без JavaScript.
Исключение участников и изменение их исторических очков сюда не входят.
